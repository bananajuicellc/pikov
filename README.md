# Pikov

![personal](https://img.shields.io/badge/maintained-personal%20project-blue.svg)

Open source multiplatform pixel and fiber arts design tool.

## Why?

I would like to work on my pixel art on my phone, tablet, or computer and have it work seamlessly together in a [local forst](https://www.inkandswitch.com/essay/local-first/) way. I would also like to be able to export my projects as a timelapse to better demonstrate my process when sharing my work. I would also like to use the same tools I use in pixel art to design knitting and cross stitch patterns.

None of the other apps I have tried were quite suited to this, therefore: https://xkcd.com/927/ For a project that helps bring various apps to work together, see https://github.com/bananajuicellc/pixel-art-converter .

## Contributing

Pikov is a human creative endeavor. I will not be accepting AI contributions to this project, as my aim is for it to be a collaborative, educational project.

See the [CONTRIBUTING
doc](https://github.com/google/pikov/blob/master/CONTRIBUTING.md) for more
information on how to get started.
